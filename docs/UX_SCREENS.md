# RECLAIM — Initial screen specifications

## Visual direction
Premium dark, calm and focused. Avoid casino-like gamification, aggressive red warnings, or dense analytics.

### Design tokens
- Background: `#090D12`
- Surface: `#121923`
- Elevated surface: `#192330`
- Primary text: `#F4F7FA`
- Secondary text: `#98A6B5`
- Accent: `#7BE0B2`
- Warning: `#F3C969`
- Danger: `#F18B86`
- Radius: 16–24 px
- Spacing scale: 4, 8, 12, 16, 24, 32

## Screen 1 — Welcome
**Purpose:** Communicate the promise without fear or shame.
- Wordmark RECLAIM.
- Headline: “Your attention is yours.”
- Supporting copy: “Build focus, understand your habits, and make room for what matters.”
- CTA: “Build my plan”.
- Secondary: privacy note.

## Screen 2 — Choose your priorities
**Purpose:** Personalize success criteria.
- Multi-select: study, meaningful work, reading, sleep routine, time with people, creative projects.
- Ask “What would you like more time for?”
- Allow skip and later editing.

## Screen 3 — Choose distracting apps
**Purpose:** Let users identify which apps they personally consider distracting.
- App list from installed apps only if justified and policy-compliant; otherwise let user select from usage data after permission.
- Explicitly say that app names and usage durations are used, not content.
- No preselected “bad” apps.

## Screen 4 — Usage access explanation
**Purpose:** Obtain informed permission.
- Explain Android Usage Access in plain language.
- Explain what is collected, why, where it is processed, retention, and how to revoke.
- Button opens Android Usage Access settings.
- Continue without permission; focus timer and exercises still work.

## Screen 5 — Home dashboard
**Purpose:** A calm daily overview.
- Greeting and selected priority.
- “Today” card: focus minutes, focus sessions, selected-app usage.
- Primary CTA: Start focus.
- Daily cognitive challenge card.
- One behavior insight with evidence and dismiss/snooze controls.
- No infinite feed.

## Screen 6 — Focus session
**Purpose:** Make the next task concrete.
- User-written task intention.
- 15/25/45-minute preset and custom duration.
- Large timer and pause/end actions.
- Optional quiet-mode instructions; no unapproved blocking.
- Completion reflection: “What did you make progress on?”

## Screen 7 — Cognitive gym
**Purpose:** Practice independent reasoning.
- One exercise at a time.
- Exercise types: argument evaluation, assumptions, evidence quality, inference, reading comprehension.
- Explain answer and reasoning after response.
- Track performance by skill and difficulty, not a single “IQ” score.

## Screen 8 — Weekly review
**Purpose:** Reflect without judgment.
- Trends in selected-app usage and focus sessions.
- Cognitive exercise practice and accuracy by skill.
- “What helped?” and “What should change?”
- Recommendations with “why this suggestion” explanation.

## Navigation
Bottom tabs: Home, Focus, Train, Insights, Profile.

## Empty states
- No usage permission: show a useful privacy explanation and keep non-tracking features available.
- No baseline: say “Collecting your first few days of data” rather than fabricate comparisons.
- No exercise history: encourage a first challenge without a streak penalty.
